# The Inner Ring

An interactive perception instrument set inside a living toroidal channel.
The observer faces across the tube's hollow cross-section while the ring turns
through an unseen pressure field. Its walls undulate, terrace into gear-like
steps, and become increasingly psychedelic as the observer approaches either
membrane.

**Live experience:** <https://clangky.github.io/inner-ring/>

## Entering the ring

- Drag to look around the channel.
- Scroll or use `W` / `S` to move backward and forward.
- Double-click to restore the original gaze.
- Use **Position** for exact placement between the back and front membranes.
- Use **Spine** to change posture, horizon, and bodily coupling to the field.
- Change **Pressure**, **Teeth**, and **Turning** to alter the channel itself.
- Send a pressure pulse to watch a temporary wave cross the membrane.

The piece is designed for desktop and mobile browsers with WebGL support. It
honors reduced-motion preferences by slowing its autonomous movement.

## Run locally

```bash
npm install
npm run dev
```

Create the static production build with:

```bash
npm run build
```
